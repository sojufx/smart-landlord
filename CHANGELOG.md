# Changelog

## Unreleased

### Added

- Global search across properties, tenants, contracts, compliance, documents, expenses and other modules.
- Consolidated tenant profiles with contact editing, linked contracts, payment history, communication notes and a secure document vault.
- Multi-file evidence uploads for repairs, inspections, inventories, expenses and property photos.
- Property utility-supplier fields and a photo gallery.
- Rent Smart Wales registration and licence certificate uploads.
- Automatic 90-day renewal reminders for Rent Smart Wales registration and licence dates.
- Smoke and CO2 alarm compliance as a trackable certificate category.
- Explicit certificate names on dashboard expiry alerts.

### Changed

- Compliance records are grouped by property address.
- Property links in contract views show the full address.
- New invoices default to today's issue date and a due date 14 days later.
- Selecting a landlord on an invoice populates the billing name and correspondence address.

### Fixed

- Missing compliance inspection/expiry dates are rejected for active records and displayed clearly as "Not set".
- Invoice totals handle multiple charge types and mixed VAT rates correctly.
